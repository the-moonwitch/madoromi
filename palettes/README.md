# madoromi palettes

Four seasons (haru 春, natsu 夏, aki 秋, fuyu 冬), each by day (hiru 昼, light) and by night (yoru 夜, dark). Every colour is one of Pilot's iroshizuku inks at some dilution; `madoromi.json` names the ink behind each one.

Everything here is generated by `bun run palettes`.

## Tokens

- `madoromi.json`: every flavour's colours (hex, oklch, source ink), the ANSI colours and the role each port gives each colour.
- `css/madoromi.css`: custom properties per flavour, e.g. `<html data-madoromi="aki-yoru">` then `color: var(--madoromi-sumi)`.

## Terminals

- **Ghostty**: copy `ghostty/*` to `~/.config/ghostty/themes/`, then `theme = light:madoromi-haru-hiru,dark:madoromi-haru-yoru`.
- **Kitty**: copy `kitty/*.conf` to `~/.config/kitty/themes/`, then `kitten themes` (or `include themes/madoromi-haru-yoru.conf`).
- **WezTerm**: copy `wezterm/*.toml` to `~/.config/wezterm/colors/`, then `config.color_scheme = "madoromi haru-yoru"`.
- **Alacritty**: copy `alacritty/*.toml` to `~/.config/alacritty/themes/`, then `[general] import = ["~/.config/alacritty/themes/madoromi-haru-yoru.toml"]`.
- **iTerm2**: Settings → Profiles → Colors → Color Presets… → Import…, and pick `iterm2/*.itermcolors`.

## Editors

- **VS Code**: `cp -r vscode ~/.vscode/extensions/madoromi`, restart, then Preferences: Color Theme → madoromi ….
- **Zed**: copy `zed/madoromi.json` to `~/.config/zed/themes/`, then pick madoromi … in `theme selector: toggle`.
- **Neovim**: add `palettes/nvim` to your runtime path (e.g. lazy.nvim `{ dir = "…/palettes/nvim" }`), then `:colorscheme madoromi-haru-yoru`.
