# madoromi palettes

Four seasons (haru 春, natsu 夏, aki 秋, fuyu 冬), each by day (hiru 昼, light) and by night (yoru 夜, dark). Every accent is one of Pilot's iroshizuku inks at some dilution, and the neutrals carry the cast of each season's grey ink; `madoromi.json` names the ink behind each colour. Which colour goes where: [style-guide.md](style-guide.md).

Everything here is generated by `bun run palettes`. The examples use haru-yoru; swap in any theme. Each release also has every port zipped, and the VS Code extension as `madoromi.vsix`: https://github.com/the-moonwitch/madoromi/releases/latest

## terminals

### Ghostty

1. Run this to fetch the day and night themes for your season.
2. Add to your Ghostty config: `theme = light:madoromi-haru-hiru,dark:madoromi-haru-yoru`

```sh
curl -fsSL --create-dirs -o ~/.config/ghostty/themes/madoromi-haru-hiru https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/ghostty/madoromi-haru-hiru -o ~/.config/ghostty/themes/madoromi-haru-yoru https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/ghostty/madoromi-haru-yoru
```

### Kitty

1. Run this to fetch the theme.
2. Add to `kitty.conf`: `include themes/madoromi-haru-yoru.conf`

```sh
curl -fsSL --create-dirs -o ~/.config/kitty/themes/madoromi-haru-yoru.conf https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/kitty/madoromi-haru-yoru.conf
```

### WezTerm

1. Run this to fetch the theme.
2. Add to your WezTerm config: `config.color_scheme = "madoromi haru-yoru"`

```sh
curl -fsSL --create-dirs -o ~/.config/wezterm/colors/madoromi-haru-yoru.toml https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/wezterm/madoromi-haru-yoru.toml
```

### Alacritty

1. Run this to fetch the theme.
2. Add to `alacritty.toml`, under `[general]`: `import = ["~/.config/alacritty/themes/madoromi-haru-yoru.toml"]`

```sh
curl -fsSL --create-dirs -o ~/.config/alacritty/themes/madoromi-haru-yoru.toml https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/alacritty/madoromi-haru-yoru.toml
```

### iTerm2

1. Run this; iTerm2 opens the theme and adds it to its presets.
2. In Settings → Profiles → Colors → Color Presets, choose madoromi haru-yoru.

```sh
curl -fsSL -o /tmp/madoromi-haru-yoru.itermcolors https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/iterm2/madoromi-haru-yoru.itermcolors && open /tmp/madoromi-haru-yoru.itermcolors
```

## editors

### VS Code

1. Run this to install the extension (it has every theme).
2. Run Preferences: Color Theme and choose madoromi haru-yoru.

```sh
curl -fsSL -o /tmp/madoromi.vsix https://github.com/the-moonwitch/madoromi/releases/latest/download/madoromi.vsix && code --install-extension /tmp/madoromi.vsix
```

### Zed

1. Run this to fetch the themes (one file has them all).
2. Run `theme selector: toggle` and choose madoromi haru-yoru.

```sh
curl -fsSL --create-dirs -o ~/.config/zed/themes/madoromi.json https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/zed/madoromi.json
```

### Neovim

1. With lazy.nvim, add this to your plugins. It loads the theme from this repository.

```lua
{
  "the-moonwitch/madoromi",
  lazy = false,
  priority = 1000,
  config = function(plugin)
    vim.opt.rtp:append(plugin.dir .. "/palettes/nvim")
    vim.cmd.colorscheme("madoromi-haru-yoru")
  end,
}
```

## tokens

### CSS

1. Add this to your page. Then set `data-madoromi="haru-yoru"` on an element and use `var(--madoromi-sumi)` and the other colours inside it.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/the-moonwitch/madoromi@main/palettes/css/madoromi.css">
```

### JSON

1. Every theme's colours (hex, oklch and the ink each comes from), terminal colours, and which colour each role uses.

```sh
curl -fsSL -O https://raw.githubusercontent.com/the-moonwitch/madoromi/main/palettes/madoromi.json
```
