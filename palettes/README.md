# madoromi palettes

Four seasons (haru 春, natsu 夏, aki 秋, fuyu 冬), each by day (hiru 昼, light) and by night (yoru 夜, dark). Every accent is one of Pilot's iroshizuku inks at some dilution, and the neutrals carry the cast of each season's grey ink; `madoromi.json` names the ink behind each colour. Which colour goes where: [style-guide.md](style-guide.md).

Everything here is generated by `bun run palettes`. The examples use haru-yoru; any flavour works.

## terminals

### Ghostty

1. Copy the theme to `~/.config/ghostty/themes/`.
2. In your config: `theme = light:madoromi-haru-hiru,dark:madoromi-haru-yoru`.

### Kitty

1. Copy the theme to `~/.config/kitty/themes/`.
2. Run `kitten themes` and pick it, or add `include themes/madoromi-haru-yoru.conf` to `kitty.conf`.

### WezTerm

1. Copy the theme to `~/.config/wezterm/colors/`.
2. In your config: `config.color_scheme = "madoromi haru-yoru"`.

### Alacritty

1. Copy the theme to `~/.config/alacritty/themes/`.
2. Under `[general]` in `alacritty.toml`: `import = ["~/.config/alacritty/themes/madoromi-haru-yoru.toml"]`.

### iTerm2

1. Settings → Profiles → Colors → Color Presets… → Import…, and pick the theme.
2. Choose madoromi haru-yoru from Color Presets.

## editors

### VS Code

1. Unzip, and copy the `madoromi` folder (or `palettes/vscode`) to `~/.vscode/extensions/`.
2. Restart, then Preferences: Color Theme → madoromi haru-yoru.

### Zed

1. Copy `madoromi.json` (every flavour) to `~/.config/zed/themes/`.
2. Pick madoromi haru-yoru with `theme selector: toggle`.

### Neovim

1. Unzip, and add the `madoromi.nvim` folder (or `palettes/nvim`) to your runtime path, e.g. with lazy.nvim: `{ dir = "…/madoromi.nvim" }`.
2. `:colorscheme madoromi-haru-yoru`

## tokens

### CSS

1. Include `madoromi.css` (every flavour), set `data-madoromi="haru-yoru"` on an element, and use `var(--madoromi-sumi)` and the rest inside it.

### JSON

1. `madoromi.json` has every flavour's colours (hex, oklch and the ink behind each), its ANSI colours, and the role each port gives each colour.
