# madoromi palettes

Four seasons (haru 春, natsu 夏, aki 秋, fuyu 冬), each by day (hiru 昼, light) and by night (yoru 夜, dark). Every accent is one of Pilot's iroshizuku inks at some dilution, and the neutrals carry the cast of each season's grey ink; `madoromi.json` names the ink behind each colour. Which colour goes where: [style-guide.md](style-guide.md).

Everything here is generated by `bun run palettes`. The examples use haru-yoru; any flavour works. The commands run from the repository's root.

## terminals

### Ghostty

1. Put the theme file in `~/.config/ghostty/themes/`.
2. Add this line to your Ghostty config: `theme = light:madoromi-haru-hiru,dark:madoromi-haru-yoru`.

```sh
mkdir -p ~/.config/ghostty/themes && cp palettes/ghostty/madoromi-* ~/.config/ghostty/themes/
```

### Kitty

1. Put the theme file in `~/.config/kitty/themes/`.
2. Run `kitten themes` and choose it, or add `include themes/madoromi-haru-yoru.conf` to `kitty.conf`.

```sh
mkdir -p ~/.config/kitty/themes && cp palettes/kitty/madoromi-*.conf ~/.config/kitty/themes/
```

### WezTerm

1. Put the theme file in `~/.config/wezterm/colors/`.
2. Add this to your WezTerm config: `config.color_scheme = "madoromi haru-yoru"`.

```sh
mkdir -p ~/.config/wezterm/colors && cp palettes/wezterm/madoromi-*.toml ~/.config/wezterm/colors/
```

### Alacritty

1. Put the theme file in `~/.config/alacritty/themes/`.
2. In `alacritty.toml`, under `[general]`, add: `import = ["~/.config/alacritty/themes/madoromi-haru-yoru.toml"]`.

```sh
mkdir -p ~/.config/alacritty/themes && cp palettes/alacritty/madoromi-*.toml ~/.config/alacritty/themes/
```

### iTerm2

1. Open the file; iTerm2 imports it.
2. In Settings → Profiles → Colors → Color Presets, choose madoromi haru-yoru.

```sh
open palettes/iterm2/madoromi-haru-yoru.itermcolors
```

## editors

### VS Code

1. Unzip it into `~/.vscode/extensions/`; it makes a `madoromi` folder.
2. Restart VS Code, then run Preferences: Color Theme and choose madoromi haru-yoru.

```sh
cp -r palettes/vscode ~/.vscode/extensions/madoromi
```

### Zed

1. Put `madoromi.json` (it has every theme) in `~/.config/zed/themes/`.
2. Run `theme selector: toggle` and choose madoromi haru-yoru.

```sh
mkdir -p ~/.config/zed/themes && cp palettes/zed/madoromi.json ~/.config/zed/themes/
```

### Neovim

1. Unzip it into `~/.config/nvim/pack/madoromi/start/`; Neovim loads it from there.
2. Run `:colorscheme madoromi-haru-yoru`.

```sh
mkdir -p ~/.config/nvim/pack/madoromi/start && cp -r palettes/nvim ~/.config/nvim/pack/madoromi/start/madoromi.nvim
```

## tokens

### CSS

1. Include `madoromi.css` (it has every theme). Set `data-madoromi="haru-yoru"` on an element, then use `var(--madoromi-sumi)` and the other colours inside it.

### JSON

1. `madoromi.json` has every theme's colours (hex, oklch and the ink each comes from), its terminal colours, and which colour each role uses.
